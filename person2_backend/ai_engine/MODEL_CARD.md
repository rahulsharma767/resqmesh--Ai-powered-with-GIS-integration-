# ResQMesh Emergency Risk Model v1

- **Model:** multinomial logistic regression
- **Inputs:** 15 structured incident/operational features
- **Outputs:** LOW / HIGH / CRITICAL probabilities, risk score, confidence
- **Training data:** 6,000 synthetic simulation rows generated by `scripts/train_risk_model.py`
- **Purpose:** hackathon decision-support demonstration
- **Not clinical:** the training data is not real emergency/clinical data and the model is not a medical device.
- **Inference:** NumPy fallback is always available; ONNX Runtime is used when installed and the checked-in ONNX graph loads successfully.
- **Snapdragon path:** QNN Execution Provider is selected only when it is actually exposed by the local ONNX Runtime build.
- **Safety boundary:** model output is advisory. It never directly selects an ambulance, route, or hospital.

## Feature groups

Casualty burden, unconscious/critical signals, injury severity, hazard type, traffic, road disruption risk, ambulance proximity, hospital capacity, ICU/emergency availability, time-of-day, Mumbai location context and route ETA.

## Reproducibility

Run `python scripts/train_risk_model.py` from `person2_backend`. The script regenerates the synthetic dataset, NumPy model parameters and ONNX artifact with the documented seed.
